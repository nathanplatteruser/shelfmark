# Shelfmark

Family used-book shop. Scan once. Count the stamp. Keep a dollar.

**Family copy (GitHub Pages):** [nathanplatteruser.github.io/shelfmark](https://nathanplatteruser.github.io/shelfmark/)

Shop, story, and jar — three bins, no typing. The live desk with inventory, Amazon Inventory Loader, and reel is the full Shelfmark app.

Open **Shop**, tap **Start practice**, and sort Calculus → Gatsby → Boxcar → F451 → Hobbit → Huck with **Count the stamp** on. Two should be green, two ochre, two oxblood.
